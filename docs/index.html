Three practical tools

三个实用工具

Expose market data directly to any MCP client (Claude, Cursor, custom agents).

直接向任意 MCP 客户端（Claude、Cursor、自定义 Agent）暴露行情数据。

get_quote

Real-time quote for one or many symbols (up to 10 per call). Batch A-share / HK / US / Taiwan in one request.

实时报价，支持批量（单次最多 10 个）。一次请求覆盖 A 股 / 港股 / 美股 / 台股。

search_stock

Fuzzy lookup by Chinese name, pinyin initials, partial code or English name. e.g. 茅台 / TSMC.

智能搜索：中文名 / 拼音首字母 / 部分代码 / 英文名。如 茅台 / TSMC。

get_kline

Historical candlesticks (day / week / month, 20–640 bars). e.g. 600519 or 2330.TW.

历史 K 线（日 / 周 / 月，20–640 根）。如 600519 或 2330.TW。

Pricing — pay per event

计费 —— 按事件付费

No subscription, no monthly fee. You pay only when data is returned.

无订阅、无月费。仅在返回数据时计费。

Connect

接入方式

Use the hosted endpoint (recommended) or run it locally.

推荐使用云端端点，或本地自行运行。

Hosted endpoint云端端点
Local (stdio)本地（stdio）
{
  "mcpServers": {
    "stock-analyst": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://neeenja--mcp-stock-analyst.apify.actor/mcp",
        "--header", "Authorization: Bearer ${APIFY_TOKEN}"
      ],
      "env": { "APIFY_TOKEN": "" }
    }
  }
}

Get your token from Apify Console → Settings → API & Integrations.

token 在 Apify Console → Settings → API & Integrations 获取。
